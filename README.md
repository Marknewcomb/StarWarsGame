# Star Wars Game

## Ideas for the game:
- User starts the game by selecting a character
- User starts their journey in Mos Eisley
- User is a force-sensitive character
- User can select various places to visit
- User can then meet various characters
- Each character plays a role such as:
  - Trader
  - Smuggler
  - Spice user
  - Spice dealer
  - Thief
  - Local
  - Imperial
  - Rebel
  - Gambler
  - Employer
- User has limited credits
- User must gain knowledge or credits to join the rebellion
- Each day changes relative to distance traveled and tasks completed
